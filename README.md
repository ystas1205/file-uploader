# file-uploader

Менеджер для скачивания файлов на Go для командной строки.

## Установка

Сборка бинарника:

```bash
go build -o uploader ./cmd/uploader
```

Запуск без сборки:

```bash
go run ./cmd/uploader --url="https://..."
```

## Флаги

### `--url` (обязательный)

Ссылка на файл для скачивания.

```bash
./uploader --url="https://avatars.avto.ru/get-autoru-vos/6214394/11c805d81aa358bc1dc5a37878a16ae5/1200x900"
```

Вывод:

```
файл успешно загружен: "1200x900.webp", размер: 141022 байт
```

### `--out`

Путь для сохранения файла. Если не указан, имя берётся из URL.

```bash
./uploader --url="https://..." --out=image.png
```

Вывод:

```
файл успешно загружен: "image.png", размер: 141022 байт
```

### `--v`

Подробный вывод: прогресс в процентах, скорость загрузки, размер файла.

```bash
./uploader --url="https://..." --v
```

Вывод:

```
downloading 100% |████████...| (141/141 kB, 5.4 MB/s)
файл успешно загружен: "1200x900.webp", размер: 141022 байт
```
